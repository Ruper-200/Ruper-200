## 🚀 Proyecto principal

### Around The U.S.
Aplicación Front-End interactiva desarrollada con **TypeScript, Programación Orientada a Objetos y REST API**.

Permite gestionar información de usuario y tarjetas mediante operaciones persistentes con un servidor, incluyendo creación y eliminación de contenido, likes, actualización de perfil y avatar.

**Aspectos técnicos:**
- TypeScript
- Programación Orientada a Objetos
- REST API
- Fetch API
- `async/await`
- Manejo de errores HTTP
- Manipulación del DOM
- Validación de formularios
